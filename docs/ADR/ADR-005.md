# ADR-005: Logging Schema (v1)

## Status
Accepted

## Context
The platform aims to support replay, debugging,
and agent benchmarking.

## Decision

Log per tick:

- tick_id
- physics_version
- terrain_version
- world_seed
- agent_version
- observation_version
- logging_version
- position_before
- action
- reward
- energy_after
- position_after
- termination_flag

Optional:
- observation_hash

Logs must allow full replay of agent behavior
under identical world configuration.

Changes to required log fields require new logging version.

## Consequences
- Experiments are comparable.
- Replay is possible.
- Benchmark integrity preserved.
