# ADR-003: Physics Model (v1.0.0)

## Status
Accepted

## Context
The world requires a deterministic, discrete physics model
suitable for benchmarking.

## Decision

1. Physics is fully discrete.
2. No velocity or acceleration.
3. Position changes exactly 1 grid unit per movement action.
4. Gravity:
   - Applied every tick.
   - If unsupported, agent moves down 1 unit.
   - Gravity does not consume energy.
5. Tick rate: 10–20 ticks per second.
6. World stepping frequency independent of rendering.
7. Energy cost model (per successful movement):
   - Grass: 0.1
   - Rock: 0.2
   - Water: 0.4
8. Invalid actions:
   - Do not change position.
   - Do not consume energy.

## Consequences
- Physics deterministic and reproducible.
- Simplifies reasoning about agent behavior.
- Continuous physics requires new physics version.
