# ADR-004: Observation and Action Space (v1)

## Status
Accepted

## Context
Agents must interact with the world in a controlled,
versioned, and benchmark-stable manner.

## Decision

Observation format (v1):

Observation = {
    local_voxels: uint8[7][7][7],
    energy: float,
    position: (x,y,z),
    orientation: enum {N,E,S,W}
}

Voxel encoding:
0 = Air
1 = Grass
2 = Rock
3 = Water
4 = Energy

Action space (discrete):

0: MOVE_FORWARD
1: MOVE_BACKWARD
2: MOVE_LEFT
3: MOVE_RIGHT
4: BREAK
5: IDLE

Rules:
- Movement changes position by 1 unit.
- BREAK affects block directly in front.
- All actions consume 1 tick.

Changes to observation tensor shape, encoding,
or action enumeration require new observation version.

## Consequences
- Agents receive localized perception only.
- No global map access.
- Stable interface for benchmarking.
