# ADR-001: Coordinate System Definition

## Status
Accepted

## Context
The world requires a bounded coordinate system compatible with .vox
structure and deterministic indexing.

## Decision

1. World grid size: 256 x 256 x 256.
2. Index range: 0–255 inclusive on all axes.
3. Y axis represents vertical height.
4. Gravity acts along negative Y.
5. World is finite and hard-bounded (no wrap-around).
6. World state stored as dense 3D array of uint8 voxel IDs.
7. Coordinate system is right-handed.
8. Agent spawn:
   - X,Z = (127,127)
   - Y = highest non-air voxel at (127,127) + 1

## Consequences
- Memory footprint is fixed.
- No chunk streaming required in v1.
- Deterministic indexing simplifies physics.
- Wrap-around or chunked worlds require new ADR.
