# ADR-000: Determinism and Versioning Policy

## Status
Accepted

## Context
The voxel world platform is intended to support reproducible experiments,
agent benchmarking, and versioned physics. Silent changes to system behavior
would invalidate comparisons across runs.

## Decision

1. All randomness must be seeded and deterministic.
2. Physics changes require a new physics version.
3. Terrain algorithm changes require a new terrain version.
4. Terrain seed changes do NOT require a new version.
5. Observation format changes require a new observation version.
6. Logging schema changes require a new logging version.
7. Agent implementations must expose their own agent version.
8. Every experiment must record:
   - physics_version
   - terrain_version
   - world_seed
   - observation_version
   - logging_version
   - agent_version

## Consequences
- Experiments are fully reproducible.
- Agents remain comparable across terrain seeds under fixed physics.
- Breaking changes are explicit and traceable.
- Silent behavior drift is prevented.
