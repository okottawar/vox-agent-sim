# ADR-006: Containerization and Communication Model

## Status
Accepted

## Context
The system aims to support plug-and-play world and agent components
while preserving separation of concerns.

## Decision

1. World simulation runs in a Docker container.
2. Agent may run:
   - In-process (v1)
   - Or as separate container (future)
3. Communication protocol:
   - WebSocket for container-to-container communication.
   - In-process API abstraction for local testing.
4. World container is authoritative over state.
5. Viewer is read-only and does not affect simulation.

Container versioning:
- Docker image version is independent of experiment version.
- Experiment identity defined by:
  physics_version,
  terrain_version,
  world_seed,
  observation_version,
  agent_version.

## Consequences
- Plug-and-play agent integration possible.
- Separation of concerns preserved.
- Networking layer abstracted from physics logic.
