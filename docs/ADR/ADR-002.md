# ADR-002: Terrain Generation Model

## Status
Accepted

## Context
Terrain must be deterministic, configurable, and independent of physics.

## Decision

1. Terrain algorithm: 2D Perlin noise heightmap.
2. Height function:
   height(x,z) = floor(noise(x,z) * max_height)
3. Water level is fixed constant.
4. Surface blocks:
   - Top layer: Grass
   - Sub-surface: Rock
5. Energy blocks:
   - Replace surface grass blocks
   - Uniform probability p (configurable)
6. RNG seed is part of world configuration.

Versions:
- Changes to height function → new terrain version.
- Changes to block distribution rules → new terrain version.
- Changing only seed → no version change.

## Consequences
- Terrain reproducible given seed.
- Agents can be evaluated across multiple terrain seeds under same physics.
- Terrain algorithm evolution is explicitly versioned.
